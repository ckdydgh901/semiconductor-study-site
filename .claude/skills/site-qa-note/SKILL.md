# 질문 노트 기록

복습 중 대화에서 이해한 내용을 사이트의 `[질문 노트]`로 남긴다. **사용자가 기록을 부탁했을 때만** 한다.

## 하지 말 것
- "기록할까요?"라고 먼저 묻지 않는다. 자동으로 기록하지도 않는다.
- 노션 원본은 건드리지 않는다(노션 수정은 별도 요청이 있을 때만).
- 사용자 필기·댓글 박스를 고치지 않는다.

## 절차
1. **위치 찾기**: 질문이 다루는 내용이 있는 섹션(`h2`/`h3`)을 찾는다. 그 섹션의 `[사용자 노트 필기]` 박스 뒤, 섹션 끝 쪽에 넣는다. 같은 섹션에 이미 `[질문 노트]`가 있으면 그 박스 안에 `Q.`/`A.`를 이어 붙인다. 구조 순서: 섹션 제목 → 본문 → 이미지 → 노트 필기 → 질문 노트.
2. **형식**:
   ```html
   <div class="note qa"><b>[질문 노트]</b>
     <p class="q">Q. 사용자가 한 말을 다듬은 한 문장</p>
     <p>A. 대화에서 이해한 핵심 (기존 질문 노트와 같은 어투, ~다 체)</p>
   </div>
   ```
   질문은 사용자의 말을 한 문장으로 다듬고, 답은 대화에서 **사용자가 이해한 핵심**을 쓴다(내가 덧붙인 장황한 설명이 아니라). 첨자·단위는 사이트 표기(SiO₂, μm …)를 쓴다.
3. 같은 페이지 안에서 어느 섹션인지 모호하면 가장 가까운 섹션을 고르고 보고에서 밝힌다(되묻지 않는다).
4. **`topics.js`의 해당 주제 `updated`를 오늘 날짜로 갱신**한다.
5. **한 줄로 알린다**: "○○ 주제의 '섹션 제목'에 넣었습니다."
6. 확인이 필요하면 브라우저로 해당 앵커를 열어 박스가 보이는지만 가볍게 본다(서버를 열었다면 종료).
