# Word 정리노트 → 연습용 Q&A 페이지

사용자의 Word 파일 `C:\Users\user\OneDrive\바탕 화면\4-2학기\AI를 활용한 반도체 공정 장비 데이터 분석 교육\반도체 정리노트.docx`를 읽어 `topics/notes-qa/index.html`을 만든다(영역 `notes` = 상단 탭 "반도체 정리노트", 하위 탭 "Q&A 연습". 더인 교육 영역이 아니다). 노션이 아니라 Word가 원본이므로 `topics.js`에 `notion` 링크는 없다.

## 규칙
- **원문 그대로.** 질문·답·번호·오타·메모(`*…`, `(수정이 필요한 답변)`, `[최종 Boss]`, `[나중에 답안 작성하기]`)를 바꾸지 않는다. 빠뜨리지도 않는다. 빈 답(`A25-1.`)도 그대로 둔다. 구분용 `[답변]` 줄만 뺀다.
- **형식:** 질문 노트(`[질문 노트]`, 파란 박스) 하나가 `<details class="note qa qa-card">` 한 장이다. 닫힌 상태에서는 질문만, 클릭하면 답이 펼쳐진다. 위쪽에 "모두 펼치기/모두 접기" 버튼이 있다. 서버·fetch 없이 `file://`에서 동작한다(`<details>` + 작은 인라인 스크립트).
- **개인 메모·감상도 그대로 둔다**(묻지 않음). 사용자가 Word 안에 적은 메모는 답의 일부로 취급한다.
- **첨자·단위 표기**는 승인된 것만 바꾼다. 2026-11-08에 SiO2→SiO₂, Si3N4→Si₃N₄, um→μm, 10^-3→10⁻³, 10^3→10³을 승인받았고, 스크립트의 `NOTATION` 목록으로 변환 때마다 적용된다(재변환해도 유지). 그 밖의 새 후보(새로 추가된 질문 등)는 `notation-fix` 규칙대로 먼저 목록으로 물어 승인받은 뒤 `NOTATION`에 추가한다. Word는 노션이 아니므로 노션은 수정하지 않고 사이트만 고친다.
- Word가 열려 있어도 읽을 수 있지만 **저장하지 않은 수정은 파일에 없다.** 가져오기 전에 사용자가 Ctrl+S를 했는지 확인한다.

## 절차
1. 스크립트로 변환: `python .claude/skills/word-qa-practice/scripts/docx_to_qa.py "<docx 경로>" notes-qa "<작업폴더>"` (작업폴더에 docx를 복사해 읽는다). 출력: 질문 수, 섹션 시작 누락 여부, 빈 답, 질문 아래 보기가 있는 문항.
2. **섹션 묶음(`GROUPS`)**은 스크립트 안에서 질문 번호 기준으로 정한다. 새 질문이 늘면 `GROUPS`에 시작 번호와 제목을 추가한다(`unlabeled starts`가 비어야 정상).
3. **누락 검사:** Word의 모든 비어 있지 않은 문단이 페이지에 들어갔는지 확인한다(`[답변]` 제외). `missing 0`이어야 한다.
4. `topics.js`의 `notes-qa` 항목(`summary`의 문항 수, `updated`)을 갱신하고 `node -e`로 파싱을 확인한다.
5. 브라우저 확인: 로컬 서버(`python -m http.server`)로 열어 ① 카드가 모두 닫힌 채 시작 ② 클릭으로 펼침 ③ 모두 펼치기/접기 ④ 목차 ⑤ 가로 스크롤 없음. 끝나면 서버를 종료한다.
6. 사용자에게 알린다: 문항 수, 새로 늘어난 문항, 원문에서 오류로 보이지만 그대로 둔 부분, 승인을 기다리는 첨자·단위 목록.
