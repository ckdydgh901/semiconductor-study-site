# 첨자·단위 표기 수정 (사이트 + 노션 동시)

사용자는 노션에 첨자·단위를 직접 적용하지 않는다. 맥락과 배경지식으로 필요하다고 판단되면 고치되, **새 주제냐 기존 주제냐**에 따라 절차가 다르다.

## 규칙
- **새 주제(방금 옮기는 중)**: 먼저 "이런 것들을 바꿔드릴까요?"라고 **목록으로 한 번에** 묻는다. 승인 전에는 원문 그대로 둔다. 승인된 항목만 바꾼다("전부 적용"이면 목록 전체).
- **이미 사이트에 올라간 페이지**: 개선점을 발견하면 묻지 않고 바로 고친다.
- **사이트와 노션을 함께 고친다.** 사이트만 고치고 노션을 두면 다음 재변환 때 되돌아간다.
- **관용 표기는 건드리지 않는다**: Vt, Vth 등.
- **원문 오류는 고치지 않고 알린다**: 예) 파장인데 `mm`로 쓴 것, k(비유전율)에 붙은 `ev`. 단, 사용자가 그 항목을 포함해 "전부 적용"이라고 승인하면 승인된 대로 고치고, 숫자는 건드리지 않는다(예: `330-340`은 그대로).
- 한글 조사가 바로 붙은 표기(`N-로`, `P-로`)를 놓치지 않는다 → N⁻로, P⁻로.
- 변환 예: `SiO2→SiO₂`, `H2O→H₂O`, `CF4→CF₄`, `Ar+→Ar⁺`, `N+→N⁺`, `1.84um→1.84μm`, `1000A→1000Å`, `cm^2→cm²`, `8F2→8F²`, `10^-3→10⁻³`, `+-→±`, `3.9ev→3.9 eV`.

## 절차
1. **후보 스캔**: `python .claude/skills/notation-fix/scripts/scan_notation.py <topic-id> …` — 파일을 고치지 않고 후보와 문맥만 출력한다.
2. **새 주제면** 후보를 묶음별로(화학식 / 단위 / 지수·제곱 / 부호 / 따로 확인할 부분) 정리해 한 번에 묻는다. 의심스러운 원문 오류는 "따로 확인할 부분"으로 분리한다.
3. **사이트 수정**: `topics/<id>/index.html`을 Python 문자열 치환으로 고친다. 정확한 문자열을 쓰고(예: `"1000 +- 10A"`는 `"1000A"`보다 먼저), 항목별 치환 횟수를 출력해 확인한다. 치환 후 같은 스캔을 다시 돌려 남은 것이 없는지 본다. 이미지 캡션의 `<sup>/<sub>`는 건드리지 않는다.
4. **노션 수정**: `ToolSearch`로 `notion-update-page`를 불러 `update_content`로 같은 문구를 바꾼다. 같은 토큰이 여러 번 나오면 `replace_all_matches: true`. 노션 마크다운은 `^ ~ * -`를 이스케이프(`\^`)해서 저장하므로 **이스케이프 있는 형태와 없는 형태를 둘 다** 넣고(안 맞는 쪽은 `no_match` 경고만 뜬다), 경고가 예상한 것뿐인지 확인한다. 사이트 문구와 노션 문구가 다르면(PDF를 거친 경우 등) 노션에서 실제 표기를 검색해 맞춘다. 노션 쓰기는 사용자가 승인한 범위만.
5. **마무리**: `topics.js`의 `updated`를 오늘 날짜로 갱신(날짜가 다르면), 어떤 페이지의 무엇을 몇 곳 바꿨는지와 "따로 확인할 부분"을 한 줄씩 보고한다.
6. 재변환 주의: `notion2site.py`로 다시 만들 때는 노션을 다시 fetch해 새 표기가 들어온 raw로 만들어야 한다. 옛 raw로 만들면 표기가 되돌아간다.
